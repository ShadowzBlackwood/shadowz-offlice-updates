# Shadowz Offlice - actualizaciones

Repositorio **publico** que solo contiene los instaladores de **Shadowz Offlice** (Shadowz Sheets, Shadowz Write y Shadowz PDF). El codigo fuente vive en otro repositorio, privado.

Cada version es una *Release* con el instalador adjunto (`Setup_ShadowzOfflice.exe`). Las tres apps consultan aqui la ultima release al abrir y avisan si hay una version nueva; para actualizar basta descargar el instalador y ejecutarlo encima de la instalacion actual (tus documentos y ajustes se conservan).
